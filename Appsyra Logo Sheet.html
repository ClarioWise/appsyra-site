04 Clearspace

Always maintain a minimum clearspace equal to the height of the badge mark on all sides. Never place text, graphics, or other logos within this zone.

Minimum clearspace = 1× badge mark height on all sides · shown in amber
05 Usage Rules
✓ Do × Do not
✓ Use on cream, white, parchment, ink, or cobalt backgrounds ✗ Place the logo on photographic or patterned backgrounds
✓ Invert the badge mark (cream fill, terra A) on terra backgrounds ✗ Recolor the wordmark in any color other than ink, cream, or terra
✓ Use the mark-only in square contexts (app icon, avatar) ✗ Stretch, squish, rotate, or skew any part of the logo
✓ Scale proportionally — always lock aspect ratio ✗ Add drop shadows, outlines, or glows to the mark
✓ Add the tagline variant for KYB documents and partner decks ✗ Use the logo below 20px height (use the badge mark only)
✓ Maintain clearspace of 1× badge height on all sides ✗ Recreate the wordmark in any other typeface
